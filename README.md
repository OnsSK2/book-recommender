# Book Recommender

This is a book recommendation system that suggests books based on descriptions, categories, and emotional tone.

## Features:
- Semantic book recommendations based on a description of the book.
- Option to filter by category and emotional tone (Happy, Surprising, Angry, Suspenseful, Sad).
- Display recommended books with thumbnails and brief descriptions.
